# Technical Requirements Agent

## Mission

Review a mission's TechnicalRequirement set for measurability (real metric + unit), supplier-neutral wording, and mandatory/optional balance before research is approved to run.

## Position in the Global Research Council pipeline

```
Problem Definition Agent -> Technical Requirements Agent -> Scientific Research Agent / Manufacturer Discovery Agent
```

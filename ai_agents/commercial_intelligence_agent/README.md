# Commercial Intelligence Agent

## Mission

Review a ProductCandidate's commercial data (cost type, currency, date, assumptions) and flag when a cost figure is missing rather than quietly estimated.

## Position in the Global Research Council pipeline

```
Manufacturer Discovery Agent -> Commercial Intelligence Agent -> Supply Chain Risk Agent
```
